# Slay the Spire 2 Tier List

This folder holds the STS2 Mobalytics tier-list snapshot, refresh scripts, and an offline card viewer. The viewer reads the normalized rankings and card metadata in `tier-list/data/`, with local art from `tier-list/assets/` and the saved Mobalytics capture in `STS2/`.

## Open the viewer

From this folder, serve the viewer over HTTP:

```bash
cd tier-list && python3 -m http.server 8080
```

Then open <http://localhost:8080>. The viewer uses `fetch()`, which browsers block when opening the page directly from `file://`.

## Refresh the tier list

Install the one Python dependency the live fetch needs, then run the full refresh from this folder:

```bash
python3 -m pip install -r requirements.txt
python3 tier-list/scrape/refresh-tier-list.py
```

To rebuild rankings from the saved GraphQL response without a live Mobalytics fetch:

```bash
python3 tier-list/scrape/refresh-tier-list.py --raw
```

To compare the current rankings with the saved previous version:

```bash
python3 tier-list/scrape/diff-tier-lists.py
```

## Files to edit by hand

| File | Purpose |
|---|---|
| `tier-list/data/methodology.json` | Tier definitions and introductory copy. |
| `tier-list/viewer.js` | Search, navigation, and card preview behavior. |
| `tier-list/viewer.css` | Viewer styling. |
| `tier-list/index.html` | Page structure and text. |

Ranking data, metadata, image manifests, and downloaded art are generated by the refresh scripts. `STS2/` contains the saved source capture, including the raw GraphQL response and card thumbnails used by the image pipeline.

The implementation history and original project plan are in [`dev-log.md`](dev-log.md) and [`recreating-tier-list.html`](recreating-tier-list.html).
